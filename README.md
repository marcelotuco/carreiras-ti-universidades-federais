# Carreiras de TI nas universidades federais

Painel com o quadro de pessoal, a remuneração básica, a carreira e o impacto orçamentário dos analistas e técnicos de TI das universidades federais (jan/2013 a set/2026).

Os dados são agregados, sem identificação de servidores, e vêm dos dados abertos de servidores civis do Poder Executivo federal (Portal da Transparência, SIAPE). A página é um único arquivo (`index.html`) e não usa serviços externos.
